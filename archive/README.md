# Earlier project versions

`results_v1/` contains the original eight-player experiment with nonzero costs.
`results_v2_costs/` contains the nine-player version-0.2 experiment with nonzero costs.
`README_v0.3.md` and `PROJECT_v0.3.md` preserve earlier documentation and historical defaults.
Those documents retain the paths and player counts used at the time.

Use the root README and `docs/` for current instructions. Current zero-cost six- and
nine-player reference experiments are under `results/` at the repository root.
